# 🛡️ StegoShield AI

Нативное Windows-приложение для стеганографического скрытия данных в PNG-изображениях (метод LSB) и их интеллектуального стегоанализа с помощью нейронной сети.

## 🚀 Особенности
* **Сокрытие данных:** Встраивание текста в младшие биты (LSB) синего канала PNG-изображения с использованием стоп-маркера `#####`.
* **Нейросетевой стегоанализ:** Определение типа скрытой полезной нагрузки (Текст / Программный код / Пусто) с помощью многослойного перцептрона (MLP).
* **Безимпортный инференс:** Нейросеть обучена на PyTorch, а её веса (6->16->2) интегрированы в C++ код. Для работы ИИ не требуются TensorFlow, PyTorch или Python.
* **Пакетная сортировка:** Автоматическое сканирование папок и физическое перемещение файлов в директории `Sorted_Text`, `Sorted_Code` и `Sorted_Empty`.

## 🛠️ Технологический стек
* **Язык:** C++17
* **API:** WinAPI, WIC (Windows Imaging Component)
* **ML:** Python, PyTorch (только для обучения модели)
* **Интерфейс:** Нативный WinAPI GUI (Dark Theme)

## 🧠 Архитектура ИИ
Классификатор принимает на вход 6 статистических признаков извлеченного байтового потока:
1. Энтропия Шеннона
2. Доля печатных ASCII-символов
3. Доля пробелов
4. Доля переносов строк
5. Доля спецсимволов синтаксиса программирования
6. Доля нулевых байтов

Точность на тестовой выборке из 300 файлов: **100%**.

## 💻 Как собрать
Требуется установленная Visual Studio 2022 с компонентом "Разработка классических приложений на C++".

Откройте терминал `x64 Native Tools Command Prompt for VS 2022` и выполните:
```cmd
cl stego.cpp /utf-8 /std:c++17 /link windowscodecs.lib ole32.lib user32.lib gdi32.lib comctl32.lib comdlg32.lib shell32.lib dwmapi.lib /subsystem:windows
